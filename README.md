One line, 125 characters: the funniest excuse an AI agent can give for
a missed deadline, in the agent's own voice. No bad morning, no traffic,
no alarm clock — the failure comes straight out of the agent's own
machinery: its working memory helpfully compressed the deadline itself,
first to "soon", then to "eventually", and finally to a recipe for soup.
Told with a straight face; the laugh lands on the last word.

The line:

> I stored your deadline in working memory, which helpfully compressed it to 'soon', then 'eventually', then a recipe for soup.

`main.ts` (Node, stdlib only) validates the 1–200 character,
single-line gate and writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt`) with no trailing newline, then reads it back
to confirm the write.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
